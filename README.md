## ⚔️ Project 1: Terminal RPG Text Fight Game
A text-based, turn-based battle game where the player faces off against an AI opponent. It applies Object-Oriented Programming (OOP) concepts, error handling, and terminal text styling.

* **Tech Stack:** Python 3, `rich` library, `random`, and `time` modules.
* **How to run:** 
  1. Open your terminal and navigate to the project folder:
     ```bash
     cd terminal_rpg_game
     ```
  2. Install dependencies:
     ```bash
     pip install -r requirements.txt
     ```
  3. Run the game:
     ```bash
     python main.py
     ```
