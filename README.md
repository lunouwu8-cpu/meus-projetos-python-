### ⚔️ Projeto 1: Terminal RPG Text Fight Game
Um jogo de batalha baseado em turnos e texto onde o jogador enfrenta um oponente controlado por uma I.A. simples. O projeto aplica conceitos de Programação Orientada a Objetos (POO), tratamento de erros e estilização de texto no terminal.

* **Tecnologias:** Python 3, biblioteca `rich`, módulos `random` e `time`.
* **Como rodar:** 
  1. Abra o terminal e navegue até a pasta do projeto:
     ```bash
     cd terminal_rpg_game
     ```
  2. Instale as dependências:
     ```bash
     pip install -r requirements.txt
     ```
  3. Execute o jogo:
     ```bash
     python gamerpg.py
     ```

